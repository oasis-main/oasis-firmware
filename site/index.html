Oasis Studio
Overview Download Source

Build hardware. Fix the hardware you already have.

Oasis Studio is a free, open-source desktop app for microcontrollers and single-board computers. Describe a device, generate its firmware, and put it on an ESP32, RP2040, STM32, Arduino, or Raspberry Pi. Then point the same tools at a device you own and find out what it does.

One tool set, two directions

Most tools help you make a new board work. Oasis Studio also helps you understand a board that someone else made.

Design

Write one device.yaml: the board, the sensors, the actuators, the control loops.

Oasis Studio checks the file and writes Rust firmware for the board. The same file also feeds a KiCad schematic scaffold and a parts list.

Reach

See every board on USB, with its USB id, serial number, and board family.

Oasis Studio finds your flash tools (espflash, probe-rs, picotool, avrdude, mpremote) and builds the exact command for each board.

Investigate

Work on hardware you own: a dead smart-home device, a gadget with a closed app, an old controller.

Read what the device reports, back up its firmware before any change, and replace the firmware when the vendor is gone.

Safe by design

A tool that can flash firmware can also break a device. These rules are in the code, not only in the manual.

Your devices only

Oasis Studio writes only to devices in your owned-device list. You add each device and confirm that you own it. A flash to any other device is refused.

You confirm every flash

Before a flash, the app shows the board, the port, the tool, every argument, and the firmware hash. Nothing runs until you press the button.

No shell strings

The app starts each tool with a list of arguments. A port name or a file name cannot turn into a second command.

A log of every change

Each device added, each firmware build, and each flash plan writes one line to a local activity log. The log stays on your computer.

An assistant that proposes

The assistant uses the same functions as the buttons. It can read a datasheet, explain a validation error, write a driver, and prepare a flash plan. It cannot flash or command a device by itself. Chat arrives with account sign-in in a later release. Everything else works offline, with no account.
