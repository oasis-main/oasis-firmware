Oasis Studio
Overview Download Source

Design, simulate, and flash firmware for the boards you own.

Oasis Studio is a free, open-source desktop app for small hardware projects: sensor nodes, greenhouse and farm controllers, and hobby robots. Find your boards on USB, run firmware in a simulator, and flash a board after you check the plan. The app works offline, with no account. An AI agent can use the same tools through MCP. Only a person can write firmware to a board.

From a file to a board

Each step has its own page in the app. An AI agent can do the same steps through MCP, except the write to a board.

Design

Write one device.yaml: the board, the sensors, the actuators, and the control loops. Oasis Studio checks the file and generates a Rust firmware project.

The KiCad bridge reads a KiCad project into a device.yaml, and writes a KiCad project with a parts list template from a device.yaml.

Simulate

Run a firmware file with no board connected: an Arduino Uno in simavr, or an STM32F103 in Renode.

Each run has a time limit. The app shows the UART output of the firmware.

Flash

The Hardware page lists each serial port with its USB id, serial number, board family, and the flash tools that are installed.

The Flash page builds a plan for the board. After you confirm the plan, the app backs up the current firmware, writes the new firmware, and verifies the write.

Safe by design

A tool that can flash firmware can also break a board. These rules are in the code, not only in the manual.

Your boards only

Oasis Studio writes only to a board in your owned-device list. Only a person adds a board to the list. The app refuses a flash to any other board.

You confirm every write

Before a flash, the app shows the board, the port, the tool, every argument, the SHA-256 hash of the firmware, and the backup step. Nothing runs until you confirm.

No shell

The app starts each tool with a list of arguments. No shell reads the arguments, so a port name or a file name cannot become a second command.

Each change is logged

Each change writes one line to a local action log: the time, the actor (you, the assistant, or an MCP client), the action, and the result. The log stays on your computer.

Works with AI agents

The MCP (Model Context Protocol) server oasis-studio-mcp gives an agent the same functions as the app. It works with Claude Code, Claude Desktop, Cursor, and other MCP clients. The agent can list boards, validate a device.yaml, generate firmware, run a simulation, and prepare a flash plan. No MCP tool writes to a board. The setup steps are in the README.
