Install notes

Version 0.1 is not yet signed by Apple or Microsoft. Your computer warns you the first time. These steps open the app.

macOS 11 or later

  • Open the .dmg and drag Oasis Studio to Applications.
  • Open the app. macOS stops the app the first time.
  • Open System Settings → Privacy & Security. Click Open Anyway.

Windows 10 or 11

  • Run the -setup.exe or the .msi.
  • If SmartScreen shows a warning, click More info, then Run anyway.
  • Board drivers: CP210x and CH340 boards can need the vendor's USB driver.

Linux

  • AppImage: chmod +x Oasis*.AppImage, then run the file.
  • Or install the .deb or .rpm with your package manager.
  • Serial access: sudo usermod -aG dialout $USER (Arch: uucp). Log out and log in.

Flash and simulator tools

Oasis Studio uses the standard open-source flash tools and simulators. One script installs the tools for your system. The script installs only what is missing, checks the SHA-256 hash of each download, and asks before each step that needs sudo. Read the script before you run it.

macOS and Ubuntu

curl -fsSLO https://raw.githubusercontent.com/oasis-main/oasis-firmware/master/scripts/setup/setup.sh
less setup.sh
bash setup.sh

macOS needs Homebrew. Ubuntu 22.04 or later.

Windows 10 or 11

Invoke-WebRequest -UseBasicParsing -OutFile setup.ps1 https://raw.githubusercontent.com/oasis-main/oasis-firmware/master/scripts/setup/setup.ps1
notepad setup.ps1
powershell -ExecutionPolicy Bypass -File setup.ps1

No administrator permission needed. Programs go in your user folder.

The default set is the flash tools: arduino-cli and the Arduino AVR core, avrdude, espflash, probe-rs, picotool, and mpremote. Add --tools full (Windows: -Tools full) for Rust and the simulators. --dry-run shows the plan and installs nothing. Manual steps for each tool: docs/INSTALL_TOOLCHAINS.md.

Build from source

Needs Rust (stable) and Node.js 20 or later. Linux also needs the WebKitGTK and libudev development packages.

git clone https://github.com/oasis-main/oasis-firmware
cd oasis-firmware/desktop
npm ci
npm run tauri build

Full steps: docs/STUDIO_RELEASE.md.
